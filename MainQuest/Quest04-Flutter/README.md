# Pixel Party  
## 평가 루브릭  
[] 기본 기능 구현 및 UI 디자인   
    - 앱이 오류 없이 실행되며 기본 기능이 작동한다.  
[] 데이터 모델 및 상태 관리  
    - 데이터가 UI에 올바르게 표시되고 업데이트된다.   
[] 네비게이션 및 사용자 상호작용  
    - 최소 2개 이상의 화면 간 이동이 가능하다.   
    - 사용자 입력에 대한 적절한 응답과 피드백이 제공된다.  
[] 고급기능 및 외부 서비스 연동  
    - 외부 API 연동이나 실시간 데이터 동기화 기능이 구현되어 있다.   
[] 코드 품질 및 창의성  
    - 코드가 잘 구조화되어 있고 가독성이 좋다.  
    - 앱의 주제나 기능이 독창적이고 창의적이다.

## 기획
### Key Features  
'''  
  
협업 캔버스 - 사용자들이 함께 작업할 수 있는 단일 캔버스 제공  
실시간 업데이트 - 모든 픽셀 변경사항이 즉시 모든 사용자에게 동기화됨  
미니멀 UI - 색상만 선택하여 픽셀을 클릭해 색상 변경 (별도의 지우개 도구 없음)  
  
'''  
### Additional Feautres  
'''
  
커서 인식 기능 - 다른 사용자의 커서 위치와 이름을 실시간으로 표시  
자동 픽셀화 - 이미지 업로드 시 자동으로 16비트 픽셀 아트 스타일로 변환  
마이크로 애니메이션 - 픽셀이 배치될 때 미세한 애니메이션 효과 추가  
하단 컬러 팔레트 - 항상 화면 하단에 표시되는 색상 선택 바    
  
'''    
### 기술적 도전 과제  
'''  
[] 실시간 통신 - WebSocket을 활용한 여러 사용자 간의 동시 작업 구현  
[] 상태 동기화 - 캔버스의 상태를 실시간으로 모든 사용자에게 전파  
[] 이미지 처리 - 업로드된 이미지를 효율적으로 픽셀화하는 알고리즘 구현  
[] 사용자 제한 - 최대 N명으로 연결 제한하는 기능 구현  
[] 서버 배포 - 외부 접속이 가능한 서버 구성 (Render 또는 ngrok 활용)  

'''
